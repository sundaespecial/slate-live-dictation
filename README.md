# Slate — Live Dictation

An Android dictation and note-taking app by Elijah Wright.

## Download

[Download Slate 1.3.7-hazed.1](https://github.com/sundaespecial/slate-live-dictation/releases/latest)

Open the release and download `Slate-1.3.7-hazed.1.apk`. Requires Android 7.0 or newer. Open the APK on your Android device and allow installation from the app used to open it when prompted.

This release is the exact APK retrieved from the author's installed phone app. The APK is distributed unchanged, preserving its existing signing identity. This repository contains the downloadable Android build and release documentation; application source code is not included.
